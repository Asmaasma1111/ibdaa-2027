# موضوعات إبداع ٢٠٢٧

صفحة لطالبات مدرسة محمد بن إبراهيم الخضير الثانوية للموهوبات لمعرفة موضوع مشروعهن في «إبداع» ٢٠٢٧.

هذا المستودع يحتوي الواجهة فقط. لا توجد فيه أي بيانات عن الطالبات أو الموضوعات؛ كل التحقق يجري في خادم خاص على Google Apps Script.

This repository holds only the public front end. It contains no student data. All checks run on a private Google Apps Script backend.
